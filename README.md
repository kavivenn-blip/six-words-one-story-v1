A program that writes one complete story in exactly six words: "He dug one grave. Two names." One digger, one grave, two names — the turn lands in the second sentence, and the reader fills in who the second name belongs to and why there is only one grave.

## Run it

```sh
python3 main.py
```

This writes the story to `/output/entry.txt` (UTF-8, no trailing newline, 28 characters, exactly six words). Deterministic, offline, standard library only.
